## Overview
AI Drive is an AI-powered cloud drive delivered through an Edge extension.

## Core Features
1. **Core Drive** - Auth, file listing, upload, download, navigation
2. **Knowledge Layer** - Semantic search, summaries, ask-file, related discovery
3. **Management Layer** - Auto classification, archive suggestions, governance
4. **Action Layer** - Agentic tasks, structured extraction, multi-file workflows
